# Dataset Shape Analysis Toolkit

The **Dataset Shape Analyzer** is designed to help users analyze the structure and characteristics of datasets. By understanding dataset properties like dimensionality, sparsity, distribution, and balance, this toolkit assists in evaluating whether a dataset is well-suited for specific tasks such as machine learning, statistical modeling, or data visualization.

## Features

- **Dimensionality Analysis**: Examine the number of features and records in the dataset.
- **Distribution Insights**: Analyze statistical properties, including mean, variance, skewness, and kurtosis.
- **Data Quality Metrics**: Evaluate missing values, outliers, and sparsity.
- **Class Balance Check**: Assess label distribution for classification tasks.
- **Visual Summaries**: Generate plots like histograms, correlation matrices, and PCA visualizations.
