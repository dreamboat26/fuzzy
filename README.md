# Quantum Wave Function Evolution in Fractal and Curved Geometries

This project simulates the time evolution of a quantum wave function on a 1D grid under different geometries: **Euclidean**, **Hyperbolic**, **Spherical**, and **Fractal**. The aim is to explore how the wave function behaves when subjected to different curvature effects and how it evolves over time.

## Features
- **Quantum Wave Function Simulation**: Evolves a Gaussian wave function using various Laplacian operators.
- **Geometries Supported**:
  - **Euclidean**: Flat space.
  - **Hyperbolic**: Non-Euclidean, hyperbolic curvature.
  - **Spherical**: Positive curvature (like a sphere).
  - **Fractal**: Fractal geometry with power-law scaling.
- **Metrics Calculated**:
  - Variance
  - Peak Amplitude
  - Shannon Entropy

## Visualizations
- **Wave Function Evolution**: Displays how the wave function's probability density (`|ψ|^2`) evolves over time.
- **Metrics Over Time**: Compares the variance, peak amplitude, and entropy for each geometry type.
- **Laplacian Operators**: Visual representation of Laplacian operators for each geometry.

## Objective
This experiment investigates how quantum wave functions behave in non-Euclidean geometries and whether the usual concepts of wave function collapse apply differently in spaces with fractal or non-standard curvatures.
